# 嘴部同帧验证第一轮

日期为 2026-11-20。现状已先提交为 2357bb8，包含 v60–v77 代码、当前运行模型、数值证据及第三方审阅和验证计划。新一轮按 [嘴眼验证计划](validation-next.md) 先完成模型输入、H1 测量偏差、H2 分母及 H3 裁图的有界对照。

生产模型、口型曲线、三取二和固件均使用 v77。此次实验只回放公开素材，运行时无需个人校准。

## 实验设置

- 13 张公开 Talking Face 图，包含原有四档口型、普通与近景张嘴、闭嘴及三张抿嘴。10 张有既有人工嘴角及三处内唇参考；另三张目检为唇接触，真实开口按零计，不对其唇线绝对位置作精细评分。
- 原有 10 张回放沿用 RGB332 调色板生成 RGB565 的颜色路径，四档直接复用旧回放数据。三张抿嘴沿用此前全彩高质量 JPEG，在板上解码成 RGB565。
- 每张图在真实 v77 跟踪逻辑中预处理四次，13/13 张完成跟踪，再固定最后一次实际裁框。对每张图分别跑原框、横向 ±2%、纵向 ±2% 和 ±5% 框边长、同中心缩放 0.90/1.10，共 117 次原生 ESP-DL 推理。
- 取回 13 个原框和 6 个指定扰动框的真实 112×112 RGB565 输入。19/19 份输入长度及 SHA-256 核对后，在 PC 用同一输入跑 FP32，保持 BGR/255。PC 仅做离线模型和数据核对。
- 所有坐标先映射回同一 240×320 源画面，原始像素间隙、嘴宽、两眼中心距和动画量分别记录。单帧扰动的动画数值从闭合端初始化映射，不能替代具有历史状态的动态验收。

原始回放图、模型输入、浮点输出和串口数据保留在工程本地实验目录，工程证据只保存数值汇总。本批来自同一公开人物，不能据此估计多人泛化率。

## 1. 下唇仍在模型输入内，但唇点有明显误差

10 个有人工参考的样本各有 9 种裁法，90/90 个输入中的三处人工下内唇点均处于 112×112 裁图内。原框下，人工下唇的纵坐标约落在模型输入第 75–93 行。明确大张嘴的原框并没有把下唇裁出输入。

| 同一原框和实际板上输入 | 人工内唇间隙 | 板上 PFLD | 同输入 FP32 |
| --- | ---: | ---: | ---: |
| 微张 grade-1170 | 3.33 px | 3.37 px | 3.59 px |
| 半张 grade-354 | 7.99 px | 4.63 px | 4.54 px |
| 大张 grade-4110 | 21.29 px | 11.92 px | 11.78 px |
| 近景大张 wide-near | 32.41 px | 11.41 px | 10.18 px |

同输入下 FP32 也有明显低估。量化会改变具体点位，当前误差不能全部归因到板上整数计算。对于这两张大张图，保留输入下唇和加大动画增益仍不足以得到准确轮廓。

分开比较上下内唇，grade-4110 的上边缘平均向下偏约 11.7 px，下边缘平均向下偏约 2.5 px。wide-near 的上边缘平均向下偏约 10.6 px，下边缘平均向上偏约 10.2 px。不同样本的偏差方向不同，后续局部模型要同时定位两条内唇边缘。这里按既有三条人工参考及线性插值测量，标注与颜色量化带来的不确定性仍需保留。

四档源像素间隙的描述性拟合得到预测约为 0.484×参考 +1.414 px。该值只描述这四张照片，不能凭此证明具体的训练损失或条件均值机制。

## 2. H2 换眼距分母不能独立解决这批抿嘴误开

三张抿嘴的预测像素间隙约为 4.49–5.34 px，同输入 FP32 约为 4.14–5.63 px。模型在实际唇接触的画面上已经生成非零间隙。

| 抿嘴样本 | 原间隙 / 嘴宽 | 间隙 / 两眼中心距 |
| --- | ---: | ---: |
| p1280 | .0818 | .0792 |
| p1285 | .0918 | .0865 |
| p1291 | .0790 | .0739 |

为比较同等动画增益，另用公开微张图 grade-1170 的嘴宽/眼距作一次固定单位换算，仅用于离线消融。原有开度约 35.7%、42.6%、33.8%，换分母后约为 40.7%、46.3%、36.6%。

在两种归一化里，这三张闭嘴的预测间隙都高于那张明确微张图。正比例缩放和单调的动画曲线无法在保住该微张的同时把三个错误闭合读数全部压到零。本批不支持仅改分母就解决抿嘴；其他人物、侧脸和时间稳定性仍可继续评估该分母。

## 3. H3 确认了裁图敏感性，但固定移框没有形成统一修复

| 样本 | 同图九种裁法的预测间隙 / 嘴宽范围 |
| --- | ---: |
| 微张 grade-1170 | .018–.081 |
| 大张 grade-4110 | .097–.203 |
| 近景大张 wide-near | .059–.133 |
| 抿嘴 p1285 | .035–.162 |

原大张 grade-4110 同中心放大输入框 10% 后，预测像素间隙由 11.92 增至 15.25 px，仍低于参考 21.29 px；同一裁法让抿嘴 p1285 的错误间隙由 5.34 增至 8.25 px。向下移动 5% 可减轻部分抿嘴误开，却新增原闭嘴 grade-1173 的误开。

13 张图的平均像素间隙绝对误差，原框约 4.84 px，其他统一扰动约 4.86–6.68 px。上移 2% 或缩小框 10% 还会让这张微张图从闭合端无法触发张嘴。当前没有依据把某个固定移框/缩框参数替换到生产路径。

## 4. 下一步决策

本轮为“局部唇模型比较”提供了具体坏例。已经排除了这些样本下唇被输入边界裁掉的解释，同输入浮点与板端都保留偏差，换分母和统一移框没有消除它。

接下来保留这批开发坏例，补上独立公开人物的抿嘴、微张、牙齿/舌头和遮挡，再用同一嘴部裁图比较局部结构模型与 PFLD。教师伪标签先过坏例检查，两条内唇边缘、可见度和真实唇接触需要独立核对。候选参数在开发集确定，留出集另报结果。

H4 整机耗时和帧龄、近景自动重捕候选、动态联合验收及新模型训练仍属后续实验。本轮没有用静态回放推断快速收口延迟，也没有替换生产算法。
