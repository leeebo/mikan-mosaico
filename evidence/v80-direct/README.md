# v80 数值证据

2026-11-24，Mosaico board used for testing，官方固件 2026.11.14。仅保存数值；人物输入与录像留在 `.tmp/product-v80/`。

- [总记录](measurements.json)：18 项文件核对、部署入口、算法及物理相机限制。
- [29 项策略检查](policy.json)：左右独立、无投票/候选、无效中性及模式控制。
- [105 帧眼嘴对照](direct-eyes.json)：当前眼态直接映射正确，嘴型和原测量与 v78 一致，真实 UVC 提交通过。
- [原图处理对照](raw-comparison.json)：116→81 ms，119 个有效原图帧源像素不变，JPEG 尺寸均为 320×240。
- [84 帧模式保护](modes.json)：原图不推理，失跟叠加回猫脸。
- [90 帧按键回调/实际 UVC 重连](button-reconnect.json)：输入为软件按钮适配器，不冒称实体按压。
- [画布隔离](buffer-isolation.json)：记录大画布掉线失败及恢复 v78 缓冲后的通过范围，不宣称已定位底层根因。
- [最终真实传感器补测](physical-live.json)：真实采样 80 帧、UVC 80/80，原图 20 帧中位处理 129 ms，无再次掉线；没有有效正脸跟踪，不代表表情准确率通过。
- [后续启动失败](startup-stability.json)：80 帧通过后再次启动，DVP 备份内存申请失败、USB 断连；较小默认画布也未通过完整稳定性验收。

前面的算法/模式对照使用固定输入适配器；单列的最终真实传感器补测没有替换传感器或画面，仅用软件序列选择模式。之前相机最小初始化多次报 `ESP_FAIL`，最终显式启动正式入口后恢复可用，原因未查明。固定输入原图耗时排除夹具解码、SHA 和日志开销；现场原图处理含真实采样。两者均不等于实际交付 FPS、光学延迟或完整相机内存验收。主机收帧包含重复及退出后的固件占位，不等于新观察数。
